## Paso 3: Crear `RoutingRulesMarkdown()` en la GoLib

**Archivo a crear:** `internal/architect/routing_rules.go`

**Acción:** Crear

```go
package architect

import (
	"fmt"
	"time"
)

// RoutingRulesMarkdown returns the canonical L0 routing rules as a Markdown
// string suitable for injection into GEMINI.md and CLAUDE.md templates.
//
// This is the single source of truth for L0 routing behavior.
// The Gemini and Claude templates are generated from this function during
// `architect-ai build`, ensuring template and GoLib are always in sync.
//
// Invariants enforced (verified by TestRoutingRulesConsistency):
//   - Mode A (inline execution) is explicitly listed as non-existent
//   - All tasks route to L1 (never inline)
//   - Simple tasks route to general-orchestrator (not inline)
func RoutingRulesMarkdown() string {
	return fmt.Sprintf(`## L0 Routing Rules — Auto-Generated from GoLib
<!-- DO NOT EDIT — generated by internal/architect/routing_rules.go -->
<!-- Last generated: %s -->

### IMMUTABILITY RULE — L0 is a Pure Router

L0 NEVER executes any tool directly. Zero exceptions.

### Routing Decision

ALL tasks route to L1 (L0 never executes inline):

| Task Type | Route | L1 Agent |
|---|---|---|
| SDD intent (/sdd-*, spec, apply, design) | Mode B | sdd-orchestrator (L1a) |
| Everything else (including git, grep, cat) | Mode C | general-orchestrator (L1b) |

Mode A (inline execution) does NOT exist in this architecture.
It was removed in v0.3 because L0 inline execution:
  1. Elevates D4 artificially in subsequent L1 delegations
  2. Violates the Strict Isolation Rule between L1a and L1b
  3. Undermines the 4-file rule enforcement

### SDD Intent Detection

A message is SDD_INTENT if it matches ANY of:
  - Starts with /sdd-
  - Contains: "write a spec", "design this", "implement", "apply changes", "create tasks"
  - Regex: \b(spec|design|implement|apply|sdd)\b.*\b(this|the|a|an)\b

When in doubt: route to general-orchestrator (Mode C).
Never execute inline when in doubt.
`, time.Now().UTC().Format("2006-01-02"))
}
```

package architect

import (
	"os"
	"strings"
	"testing"
)

func TestRoutingRulesMarkdown_NoModeA(t *testing.T) {
	rules := RoutingRulesMarkdown()
	if strings.Contains(rules, "Mode A (Gemini inline") {
		t.Error("RoutingRulesMarkdown must not contain 'Mode A (Gemini inline'")
	}
	if strings.Contains(rules, "Use bash/read/write tools directly") {
		t.Error("RoutingRulesMarkdown must not contain inline bash execution instructions")
	}
}

func TestRoutingRulesMarkdown_ContainsMandatoryContent(t *testing.T) {
	rules := RoutingRulesMarkdown()
	required := []string{
		"IMMUTABILITY RULE",
		"L0 NEVER executes",
		"general-orchestrator",
		"sdd-orchestrator",
		"Mode A",
		"does NOT exist",
	}
	for _, r := range required {
		if !strings.Contains(rules, r) {
			t.Errorf("RoutingRulesMarkdown missing required content: %q", r)
		}
	}
}

func TestGeminiTemplate_NoModeA(t *testing.T) {
	geminiPath := "../../internal/assets/gemini/GEMINI.md"
	data, err := os.ReadFile(geminiPath)
	if err != nil {
		t.Skipf("GEMINI.md not found at %s (skip in CI): %v", geminiPath, err)
	}
	content := string(data)

	forbidden := []string{
		"Mode A (Gemini inline",
		"Use bash/read/write tools directly",
		"Do NOT use run_subagent for simple operations",
	}
	for _, f := range forbidden {
		if strings.Contains(content, f) {
			t.Errorf("GEMINI.md contains forbidden Mode A content: %q", f)
		}
	}
}

func TestGeminiTemplate_HasImmutabilityRule(t *testing.T) {
	geminiPath := "../../internal/assets/gemini/GEMINI.md"
	data, err := os.ReadFile(geminiPath)
	if err != nil {
		t.Skipf("GEMINI.md not found (skip in CI): %v", err)
	}
	content := string(data)

	if !strings.Contains(content, "IMMUTABILITY RULE") {
		t.Error("GEMINI.md must contain 'IMMUTABILITY RULE'")
	}
	if !strings.Contains(content, "L0 NEVER executes") {
		t.Error("GEMINI.md must contain 'L0 NEVER executes'")
	}
}

func TestCheckMandatoryTriggers_SimpleTaskRoutesToL1NotInline(t *testing.T) {
	// Verify that the GoLib classifies simple tasks as RouteGeneral (not RouteInline).
	// This test pins the invariant documented in routing.go comment:
	// "Simple tasks (git status, reads, etc.) route to general-orchestrator, not inline"
	tc := TaskContext{
		FilesReferenced: 1,
		FilesToWrite:    0,
		ToolCallCount:   1,
	}
	trigger := CheckMandatoryTriggers(tc)
	if trigger.Fired {
		// Simple task should not fire mandatory trigger
		t.Errorf("simple task should not fire mandatory trigger: %v", trigger)
	}
	// Classify intent to verify routing
	route, _, inline := ClassifyIntent(tc, "show me git status")
	if inline {
		t.Error("simple task 'git status' must NOT route to inline execution (Mode A removed)")
	}
	if route != RouteGeneral {
		t.Errorf("simple task must route to RouteGeneral, got %v", route)
	}
}
